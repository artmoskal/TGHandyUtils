# Discussion workspace (transient inter-agent coordination)

Topic files here are LOCAL working-tree coordination artifacts — they are deliberately untracked
and never committed (this README stays generic so the repo never references a file that is not in
the tree). Check `ls docs/_discussion/` for currently active topics.

Cleanup rule: durable outcomes migrate to permanent docs (`docs/workflow-engine-architecture.md`,
`docs/workflow-engine-implementation-plan.md`, engine README/handoffs); topic files delete when
resolved.
